Linux Libertine O Regular, Bold and Italic (`LinLibertine_R.otf`, `LinLibertine_RB.otf`, `LinLibertine_RI.otf`): the
figures' text font, the paper's own (acmart loads the `libertine` package). `use_paper_font` in the draw scripts'
common.py sets it for text and math letters. Copied from TeX Live 2023's `libertine` package (Debian
texlive-fonts-extra 2023.20240207-1, font version 5.3.0). Dual-licensed: GPL-2+ with a font-embedding exception, or the
SIL Open Font License 1.1 (LIBERTINE-COPYRIGHT).

Nimbus Roman Regular and Bold (`NimbusRoman-*.otf`, LICENSE, COPYING): the earlier figure font, for the USENIX template
(Times); no longer used. From URW's base35 fonts, tag 20200910 (https://github.com/ArtifexSoftware/urw-base35-fonts),
under the AGPL-3 with a font-embedding exception.
